# C5 — подтверждаемая доставка competitor digest

Telegram ограничивает сообщение, а прошлый digest показывал только первые десять
строк и при успехе одного send помечал полный текущий snapshot доставленным.

Новая доставка строит bounded batches до 3500 символов. Каждый batch несёт
точные ключи наград. При отказе части state объединяет с предыдущим только
подтверждённые ключи и их content hash; остальные остаются новыми для
следующего weekly run. При полном успехе, bootstrap или пустой дельте state
сохраняет полный candidate snapshot как раньше.

# C4 — точная идентичность победителя Ebirja Shop

Ebirja Shop list использует похожее имя поставщика только для выбора небольшой
очереди detail-карточек. После получения detail API победа может попасть в
weekly-дельту с любым формально корректным девятизначным ИНН, даже если этот
ИНН не относится к реестру конкурентов.

После detail-enrichment runner делает единственный допустимый identity join:
`entity_for_inn(registry, winner_inn)`. Карточка с другим, пустым или
невалидным ИНН исключается из `awards`; в receipt остаётся счётчик
`identity_rejected_count`. Успешная карточка получает имя зарегистрированной
сущности как `competitor`.

Полнота обхода не меняется: detail-карточка была прочитана, просто не прошла
строгую проверку принадлежности. Это исключает false-positive, не расширяя
поиск по похожим названиям.

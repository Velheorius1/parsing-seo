# Анализ «что приводит к договору» — все биржи (2026-07-05)

Полный проход по завершённым сделкам/договорам всех площадок в нашей БД + join к исходным лотам. Все цифры измерены, не оценены.

## 1. ETender — эталонная цепочка (join 100%)

- **1569/1570 сделок (100%) сшиты с исходным лотом** в нашей БД (ключ: короткий id из URL; сделки и лоты живут в РАЗНЫХ id-пространствах — сделки короткий, лоты display-номер. Это же было причиной «0% join» в первом проходе и 500-ок верификатора).
- **Print-scope: 19 выигранных печатных контрактов. Все 19 исходных лотов у нас были. Алерчены — 11/19 (58%).**
- **8 пропущенных победных лотов** — это готовый именованный список для обучения фильтра (пример: «Toshkandiy qalamiga mansub 1908-yilda nashr...» — переиздание книги, лот был в БД 43 дня до сделки и не алертнулся).
- **Тайминг лот→сделка: типично ~17 дней** (3–43 в выборке) — окно на подготовку КП после алерта две-три недели.

## 2. Cooperation Контракты — интенсивность конкуренции

n=115 (30 дней), print-scope=5. Поля: Победитель, Скидка, Кол-во оферт, ИНН заказчика.
- **Скидка от старта: медиана 18%, p90 38%** → для победы на cooperation закладывать ход вниз ~20%, в жёстких лотах — до 38%.
- **Конкуренция: медиана 7 оферт на лот; только 13% лотов без конкуренции.** Cooperation — самая конкурентная площадка.

## 3. UZEX Результаты — ценовая разведка + имена конкурентов

n=2127 (все с победителем и ценой), print-scope=54.
- **Скидка в print-контрактах: медиана 8.6%, p90 25%** — UZEX заметно мягче cooperation.
- **Топ победителей печатных контрактов (наши прямые конкуренты):** KANSTIK SAMARKAND MCHJ (3×), GULISTON1 (2×), COMPUTERS AND SECURITY TECHNOLOGIES (2×), TOSHKENT VILOYAT IIB BB (2×, внутр. поставщик), AKZ SOFIA MCHJ.
- Оговорка июньского калибратора остаётся: исходные лоты большинства UZEX-Результатов — закрытые каналы (силовые), контракты тут = ценовая разведка, не recall-инструмент.

## 4. Ebirja Договоры — дыра в качестве данных

Аукцион 112 / Отбор 108 / Э-магазин 2607. **extra_info ПУСТ у всех** (fetch_ebirja_contracts складывает голые строки: ни цены-скидки, ни победителя в structured-виде) + print-scope=0/1000 по title (названия — коды/generic). **Договорная аналитика по ebirja сейчас невозможна** → нужен enrichment фетчера (цена/победитель/скидка есть на источнике — июньская история: «customer+producer+prices»).

## 6. Действия (по приоритету)

1. **Конверсия-метрика в недельную рутину**: теперь можем автоматически считать «алерчен → стал контрактом» по ETender (join готов) — реальный business-outcome recall вместо прокси. + разбирать пропущенные победные лоты недели.
2. **8 пропущенных ETender-лотов** → прогнать через анализ «почему не алертнулись» (keyword-гэп? AI-reject?) → пополнить фильтр.
3. **Ebirja contracts enrichment** — вытащить цену/победителя/скидку в structured-поля (открывает договорную аналитику 2.8k контрактов).
4. **Реестр конкурентов** из победителей (UZEX + Cooperation) → в watch: их активность в живых аукционах = сигнал.

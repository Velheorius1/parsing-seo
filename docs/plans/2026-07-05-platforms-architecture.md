## 🤖 Агент-развитие: механизм авторасширения (дизайн)

Идея Данияра: система должна сама убирать косячное и ПРОБОВАТЬ находить новые лоты — «как реальный ИИ». Строим на уже работающей инфре (scheduled-Claude рутина, deepseek, investigator, recall-аудит) — три автономных прохода:

### Проход 1 — Самолечение (nightly, детерминированный)
Уже есть: recall-аудит (авто-доставка пропущенного), verifier (drop протухших), авто-мьют (шум в дайджест), healthcheck+stale-guard. Добавить: авто-применение известных фиксов по чек-листу (легаси-URL новых строк, рестарт stale-сервисов после подтверждённого правила E-H) + недельный отчёт «что вылечил сам».

### Проход 2 — Расширение поиска в SHADOW-режиме (ядро «реального ИИ»)
Champion/challenger для фильтра:
1. **Генерация кандидатов** (weekly, LLM): из побеждённых контрактов (flywheel), из кликов «Клиент» (какие слова/ТНВЭД их объединяют), из «Мимо» (анти-паттерны) → кандидаты: новые ключи (ru+uz), ТНВЭД-коды, source-параметры.
2. **Shadow-прогон** (7 дней, $0): кандидат-фильтр работает ПАРАЛЛЕЛЬНО боевому, ничего не шлёт — только логирует «поймал бы лот X» в shadow_catches.jsonl.
3. **Промоушен**: в недельном отчёте «кандидат +журнал/jurnal поймал бы 14 лотов, 11 in-scope по AI-судье — включить? [да/нет]» — one-tap. Включённые следят дальше (авто-мьют откатит, если Данияр начнёт жать «Мимо»).
→ Фильтр эволюционирует измеримо и безоткатно: никакой новый ключ не спамит, пока не доказал улов в тени.

### Проход 3 — Discovery-зонды (monthly, агентный = investigator-паттерн)
Bounded-агент (deepseek, max_turns) раз в месяц пробует по чек-листу: новые ref'ы/эндпоинты на знакомых платформах (как нашли vendor-фильтр и get_proc), server-side фильтры, новые источники из недельных находок → отчёт «нашёл дверь X, стоит подключить?».

**Гварды (все проходы):** budget-cap, fail-open, ни одного авто-изменения фильтра без shadow-доказательства + подтверждения, всё логируется в LEARNINGS. Реализация: расширение ROUTINE.md (проход 2 — ~день работы: shadow-хук в send_alerts + генератор кандидатов + отчёт; проходы 1,3 — по полдня).

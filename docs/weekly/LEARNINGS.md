- **Score** — композит 0-10 (link 25% / precision 25% / platform 20% / recall 15% / cost 15%), считается детерминированно (`weekly_metrics.py`) + браузерная проверка ссылок рутиной.

- Полные недельные отчёты: `docs/weekly/<iso_week>-report.md`. Данные: `docs/weekly/data/<iso_week>.json`.

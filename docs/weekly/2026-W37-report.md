## Находка №1 — link-integrity мерился без ожидания рендера: прошлые недели занижены

**Что произошло.** Из 11 проверенных ссылок 2 при первом открытии выглядели мёртвыми:
`xt-xarid.uz/procedure/8517095/core` отдал пустой `<body>` и заголовок `"..."`,
`new-xarid.uzex.uz/home/shop/detail/28369736` — шаблон без номера и с ценой 0.
После `wait 6s` обе отрисовались полностью и корректно:

```
Аукцион № 8517095 · ЭЪЛОН ҚИЛИНГАН · Tarmoqli-kabel, Tarnov uchun lotok, Akril gruntovka
№ SO28369736 · Книги печатные · Klassifikator 58.11.13.000-00001 · 407 100 So'm
```

Обе площадки — SPA: HTML приходит пустым, контент дорисовывает JS. Проверка без ожидания
считает живой лот битым.

**Почему это важно.** Link integrity — это 25% композита. При методике «открыл → сразу прочитал»
я бы получил 8/11 = 7.3, при корректной — 10/11 = 9.1. Разница в 0.45 балла композита
берётся из способа замера, а не из состояния площадок. Оценки W30–W36 (link 6.0–8.3)
измерялись, судя по разбросу, без гарантированного ожидания → **вероятно занижены**.

**Что сделано.** В `ROUTINE.md` ШАГ 2 внесено требование ждать рендер и перепроверять
«пустую» страницу перед тем, как засчитать её битой. Это единственная правка кода/доков
за неделю. Цифры прошлых недель НЕ пересчитываю — сравнимость ряда важнее (урок W30).

## Находка №3 — гейт TG-лидов недетерминирован и противоречит основному промпту

`TG: PR Media Group` — **самый громкий источник недели: 72 алерта из 310 (23%)**.
Лиды из TG идут не через `_RELEVANCE_PROMPT` (продуктовый скоуп), а через отдельный
`_LEAD_SPAM_PROMPT` (антиспам). Прогнал 3 размеченных лида недели через `replay --ai` дважды:

```
run 1   slim box 80x120 без печати      lead-keep → push
run 2   slim box 80x120 без печати      lead-drop → None      ← тот же вход, другой вердикт
run 1,2 Печать флага Колумбии 150х100   lead-keep → push      (оба прогона)
run 1,2 офсетная печать А3/А1, 7500 шт  lead-keep → push      (оба прогона)
```

Все три Данияр разметил как `irrelevant`.

**(а) Недетерминированность при `temperature: 0`.** Один и тот же лот на одном входе получил
разные вердикты в двух прогонах. Гейт устроен как «drop, если fast ИЛИ pro сказали drop»,
с fail-open на ошибке — то есть сетевой сбой любой из двух моделей молча превращается
в «оставить». Наблюдение на n=2, для вывода о частоте нужен прогон на десятках повторов.

**(б) Прямое противоречие двух промптов про флаги.**
`_LEAD_SPAM_PROMPT`: «ШИРОКОФОРМАТ … баннер, бекпринт, люверсы, фотообои, **флаги**, плёнка» → drop.
`_RELEVANCE_PROMPT`: «МЫ ДЕЛАЕМ … Печать на футболках, **флагах**, лентах, ткани (DTF, сублимация)».
Один и тот же предмет в одном промпте наш, в другом — нет. Разметка Данияра
(`Печать флага Колумбии` → irrelevant) говорит, что прав LEAD-промпт, а строка в
`_RELEVANCE_PROMPT` устарела. Но LEAD-промпт своё же правило не исполнил — флаг прошёл 2/2.

**Структурный контекст:** у `PR Media Group` в `mute_patterns_v1` `neg=197, pos=73`. Один ✅ = вечное
вето, поэтому авто-мьют этот канал не заглушит НИКОГДА (находка W30 в силе). Канал даёт 23%
алертов и закрывается только правкой промпта или порогом — сам собой не утихнет.

**НЕ ПРИМЕНЯЛ** — правка промпта меняет поведение на всех TG-лидах сразу, это Tier «рискованное».
Предложение к решению Данияра — ниже.

## Находка №4 (мелкая) — bypass срабатывает на имени организации

`ETender UZEX`, лот #8157: «"Davlat belgisi" MCHJ ning **Bosma fabrika** hududida texnik suv
bilan ta'minlovchi artizan **quduq** (skvajina)ni jоriy etish» — бурение артезианской скважины.
Ушёл в push, **минуя AI-гейт**: `_UZEX_NICHE_HINTS` содержит `"bosma"`, а проверка идёт
подстрокой по всему заголовку (`notifier.py:1278`) — совпало название площадки «Bosma fabrika»,
а не предмет закупки.

**Замерил масштаб, прежде чем чинить:** за 30 дней по четырём passthrough-источникам
3 969 строк, под bypass подошли 17, из них с признаками стройки — **1**. То есть дефект
реальный, но стоит ~1 ложный алерт в месяц. Правка (не отменять алерт, а лишь снимать
bypass → отдавать лот AI-гейту) безопасна и обратима, но ради одного случая в месяц
трогать горячий путь на этой неделе не стал — «один баг за раз».

## Precision — AI-судья n=12 и сверка с реальным фидбеком

Взял 12 случайных алертов недели, судил по `_RELEVANCE_PROMPT`: **7 релевантных → 5.8**.

Два элемента выборки пересеклись с реальной разметкой Данияра — оба вердикта совпали:
`Шариковая ручка` (я — не наше; он — `irrelevant`), `Бумага и изделия из бумаги`
(я — наше; он — `client`). n=2 для калибровки мало, но расхождения нет.

**Почему не взял детерминированный `precision = 1.6`** (21 FP / 25). Фидбек недели —
это то, что Данияр сам захотел разметить: он жмёт «мимо» на плохих и почти не подтверждает
хорошие. Это оценка не точности потока, а выборки, которую он счёл достойной клика.
В отличие от W30, перекоса в один канал нет (8 источников), так что данные честные — но
смещённые по отбору. Беру AI-судью, помечаю «measured, n=12».

**Ложноотрицательный, найденный фидбеком:** `Бумага и изделия из бумаги` (UZEX Предквалификации)
получил `ai=1/irrelevant` и НЕ был доставлен, а Данияр пометил его `client`. Предквалификации
приходят заголовком-категорией без позиций — судить по такому заголовку модель не может.

**Разбор доставки на 25 размеченных лотах (`replay --ai`):** доставлено 11, из них верных 3.
Каналы промахов: 3 через `lead-keep` (TG), 1 через `bypass` (Находка №4), 4 — AI дал высокий
балл (`Бирка для ключей` 90, `зип пакет` 89, `ПВХ тактиль таблица` 90, `держатель с табличкой
Брайля` 85). Оговорка: корпус смещён — это ровно те лоты, что Данияр открыл и разметил,
а не случайные 25 из 181.

Хорошо отработавший фильтр (route=None, все верно отсеяны): `Bosma platalar tutqichi`
(печатная **плата**, не печать), `Buldozerning uzatmalar **quti**si` (коробка передач),
`Qadoqlash uchun kavsharlagich` и `Упаковщик банкнот` (оборудование, не упаковка),
`Диаграммная бумага для ЭКГ`. Омонимы `bosma/quti/упаковка` ловятся ключевиком,
но AI-гейт их корректно гасит — прослойка работает.

## Предложения (НЕ применено — решение Данияра)

1. **Флаги: снять противоречие.** Убрать «флагах» из строки `_RELEVANCE_PROMPT` про печать на
   текстиле ЛИБО из списка ШИРОКОФОРМАТ в `_LEAD_SPAM_PROMPT`. Сейчас правила взаимоисключающие,
   и модель выбирает сторону произвольно. Разметка недели говорит: флаги — не наше.
2. **Стабильность гейта лидов.** Прогнать 20 лидов × 5 повторов, замерить долю расхождений.
   Если подтвердится — логировать, когда `drop` получен из-за ошибки одной из моделей
   (сейчас fail-open молчит и это неотличимо от честного `keep`).
3. **Предквалификации UZEX.** Заголовок-категория без позиций (`Бумага и изделия из бумаги`)
   AI судит вслепую — уже дал минимум один ложноотрицательный на подтверждённом лиде.
   Вариант: для `UZEX Предквалификации` не гейтить по AI, а слать в дайджест как есть.
4. **Bypass по имени организации** (Находка №4) — снимать bypass при строительных маркерах
   в заголовке. Эффект ~1 алерт/мес, риск низкий.

## Метод и ограничения

* Источник — штатные public API, которые использует UI: `xarid-api.ebirja.uz`.
  Raw pages сохранены в `ebirja-api-2025-09-21-to-2026-09-21.json` и
  `ebirja-shop-2025-09-21-to-2026-09-21.json` в этой папке (не добавлены в Git
  из-за объёма).
* `>20m` проверяется строго; ровно 20 млн не проходит.
* Name match — только очередь на верификацию реквизитов. Он не является
  доказательством юридической идентичности и не используется для суммы побед.
* Поля `title` для E-shop public contract endpoint пусты; для анализа ниши
  следующая стадия должна получать позиции/деталь лота, а не выдавать вывод по
  одному номеру договора.

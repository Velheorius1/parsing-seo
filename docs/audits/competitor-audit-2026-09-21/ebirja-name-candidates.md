# Ebirja: кандидаты побед конкурентов без публичного ИНН

Окно данных: публичный архив Ebirja, доступный с **19.11.2025** по
21.09.2026. Это не полное календарное окно с 21.09.2025: более ранних строк
публичный API не вернул даже после достижения `page_count_end`.

Собрано 29 120 доступных контрактов: E-shop 28 714, аукцион 217, тендер 2,
отбор 187. Среди 13 183 контрактов строго выше 20 000 000 UZS найдены две
уникальные процедуры с name-candidate совпадением. API списка публикует
`producer.title`, но не ИНН исполнителя. Для двух ограниченных name-candidates
отдельно запрошены их публичные карточки E-shop (`shop-view`): обе содержат
ИНН и позиции. Поэтому результаты ниже — exact-INN подтверждённые.

## Метод и ограничения

* Источник — штатные public API, которые использует UI: `xarid-api.ebirja.uz`.
  Raw pages сохранены в `ebirja-api-2025-09-21-to-2026-09-21.json` и
  `ebirja-shop-2025-09-21-to-2026-09-21.json` в этой папке (не добавлены в Git
  из-за объёма).
* `>20m` проверяется строго; ровно 20 млн не проходит.
* Name match первоначально был только очередью на верификацию; итоговое
  присвоение выше сделано только после точного `producer.tin` в публичной
  карточке. Остальные name-candidates нельзя агрегировать по имени.
* Карточки, позиции и сохранённые receipt hashes —
  `ebirja-shop-candidate-details.json` (raw artifact, не в Git). Сводка ниш и
  влияния на matcher — в `ebirja-shop-position-enrichment.md`.

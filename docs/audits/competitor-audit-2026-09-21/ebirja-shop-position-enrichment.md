## Операционный вывод

1. Пробел — не словарь, а **детальность данных**: публичный список E-shop не
   содержит title/specification, тогда как карточка содержит и ИНН, и товар.
2. Еженедельный монитор должен сначала отбирать новые договоры по точному ИНН
   либо осторожному name-candidate, затем догружать карточки только для этой
   короткой очереди. Нельзя запрашивать detail для всех договоров.
3. `CENTRIS-PRINT` оставить отдельной сущностью в отчётах. Связь с брендом
   CENTRIS не доказана, несмотря на созвучное имя.
4. Перед включением contract detail в боевой crawler нужен отдельный выпуск:
   тест на extraction, ограничение количества карточек/таймаут и проверка
   влияния на alert noise. Этот аудит production поведение не менял.

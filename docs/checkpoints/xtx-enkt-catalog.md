## ИТОГ
Канал ref_enkt_products + ref_enkt_categories на api.xt-xarid.uz/rpc — ПОДТВЕРЖДЁН, анонимный read.
- Доступ: POST https://api.xt-xarid.uz/rpc, Content-Type: application/json, без авторизации и без особого User-Agent.
- Body: {"id":1,"jsonrpc":"2.0","method":"ref","params":{"ref":"ref_enkt_products","op":"read","limit":100,"offset":N,"filters":{"code_r":"<XX.XX>"}}}
- Ограничения: limit <= 100, offset cap 3000, фильтры только ["id","type","code_r","product_id","code","category_id"], фильтра по названию НЕТ, op=count отсутствует.
- code_r: посегментный LIKE по коду (полные точечные сегменты): "17.12" работает, "17.1" → 0 строк, regex не поддерживается.
- Выгружено 13 print-релевантных классов ОКПД: 17.12(65) 17.21(13) 17.22(16) 17.23(129) 17.29(25) 18.11(1) 18.12(50) 18.13(7) 18.14(4) 58.11(24) 58.13(4) 58.14(11) 58.19(33) = 382 уникальных товара, из них 216 с прямым keyword-совпадением (бумага/бланк/тетрад/конверт/этикетк/коробк/журнал учета/...). Полная таблица — выше в этом файле.
- Запросов потрачено: 24 (бюджет ~25 соблюдён).
- Остаточный риск: товары с print-ключевыми словами ВНЕ классов 17/18/58 (например канцелярские штампы-печати 32.99, пластиковые пакеты 22.22) не выгружены — для типографского фильтра это шум, не потеря.

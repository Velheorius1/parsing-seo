3. Новые каналы — verified, по приоритету внедрения

🥇 П4. etender DealsList + NotDealedList — цены победителей + несостоявшиеся лоты
  • 156 810 сделок (растёт +1–2/мин) — победитель (имя+ИНН), цена сделки vs стартовая, заказчик. Открыт анонимно, прежний вывод «закрыт» опровергнут.
  • Print-сегмент ~220–300 сделок: PRINTUZ 1.27 млрд (реклам-полиграфия), DEKOS GROUP 298M (Uzbekistan Airways bosma, старт был 516M = −42%!), CREDO PRINT GROUP 355M, PECHATNIK VOSTOKA 547M.
  • NotDealedList 53 510 несостоявшихся: например «Keng formatli nashr» 322M, 2 участника, не разыгран — готовый лид (заказчику всё ещё надо!).
  • Рецепт: POST apietender.uzex.uz/api/common/DealsList {"From":1,"To":201} + Keyword-фильтр; деталь GetTrade/{id}/0. Заголовки не нужны.
🥈 П5. UZEX GetOffersList — э-магазин 552K с server-side print-фильтром
  • Аналог уже выстрелившего xt-xarid-shop, но на UZEX: ~21K print-офферов в 4 категориях (113765 печатные=1974, 113434 бумага=14640, 125883 издательские=3986, 126986 рекламные=368), постятся в реальном времени.
  • Жёсткости: page size = 12 (не изменяется), полный Chrome UA обязателен (иначе HTTP 500), текстовый поиск не работает — только category_id. Полный print-обход ≈ 1748 запросов, дельта в день — десятки.
  • Рецепт: POST xarid-api-shop.uzex.uz/Common/GetOffersList {"from":1,"to":12,"category_id":113765}; deep-link xarid.uzex.uz/shop/lot-details/{id}.
🥉 П7. Detail-enrichment etender + xarid — корень «5669 строк → 0 алертов»
  • Доказанный корень: list-эндпоинты не несут предмет закупки (только ОКЭД-категорию). Позиции — только в detail: GetTrade/{id}/0 (budget_products, JSON-строка → двойной parse) и GetCompetition/{id} (js_details).
  • Пример упущенного: печать газет «Yangi O'zbekiston»/«Pravda Vostoka» на 2026 год — 6.3 МЛРД сум (etender 490230, дедлайн 16.06!), журнал HAMSHIRA 227M, Guliston 168M.
  • Стоимость: бэкфилл 663 etender + 28 живых xarid ≈ 17 мин @1rps; дневная дельта ~120 лотов ≈ 3–4 мин/день. У закрытых detail отдаёт победителей с ИНН.
  • Бонус-канал тем же паттерном: GetMinimizedLotsList (592 активных аукциона xarid) — но требует RSA validation-токен (алгоритм + pubKey задокументированы в чекпоинте).
П6. xtx-request-proposals (RFP-спрос) — лёгкий, малый поток
  • ref_request_proposals_public: 15 open сейчас, print ~1–2/мес (Гувоҳнома бланки 4M, Иш журнали 68.5M). Server-side filters:{status:open} работает. Готовый yaml-конфиг в чекпоинте.
  • ⚠️ rate-limit маскируется под ошибку bad_params limit<=100 — нужен retry, не фатал.
П3-расширение. xarid-direct: category_id-фильтр (контракты-победители прямых закупок)
  • Server-side фильтр работает: 898 «Услуги печатные» + 1015 «Бумага» из 228 786. Сейчас краулим первые ~500 БЕЗ фильтра — печать тонет.
  • Свежие примеры: Давлат Белгиси ← УТЙ 33M, TOSHKENT-HUMO ← UA Technics 20M. Деталь GetDirectPurchase/{id} даёт позиции + скан договора PDF. ⚠️ json.loads strict=False (сырой \n в decree_name).
Разведка (раз в неделю): ref_special_suppliers
  • 1608 моно-поставщиков; печать = 21 поставщик / 24 кода (Давлат Белгиси — гербовые/защищённые бланки, ГУП Типография Кабмина, Узбекистон почтаси — марки). Главный вывод: по 17.23 (канцелярия/блокноты) и коммерческой полиграфии монополий НЕТ — рынок открыт. Снапшот уже выгружен (special_full.ndjson).

Config-Driven конфигурация
sources.yaml

Добавить новый источник = одна запись в YAML-файле, без написания кода

- name: etender-uzex
  adapter: api
  url: https://etender.uzex.uz/api/...
  field_map: {title: name, deadline: end_date}
  enabled: true
🔄
Оркестратор (Runner)
core/runner.py · asyncio.gather()
1
Загружает конфигурацию из sources.yaml
2
Фильтрует источники по --source флагу и enabled
3
Dispatch по типу адаптера: api → httpx, html → BS4, spa → Playwright, tg → Telethon
4
Параллельный запуск всех адаптеров через asyncio.gather()
5
Сбор результатов → List[RawTender] (Pydantic-модели)
0 * * * *
API / HTML / SPA — каждый час
0 */4 * * *
Telegram — каждые 4 часа

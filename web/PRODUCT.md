## 🎯 ПРОДУКТОВОЕ ВИДЕНИЕ

### Одна строка
**Инструмент который показывает какие ключевые слова приводят клиентов к любому сайту.**

### Проблема (через JTBD)
Люди хотят получать клиентов из поиска, но не знают какие слова использовать. Существующие решения (Ahrefs, SEMrush) стоят $99+/мес и сложные.

### Наше решение
Вводишь URL любого сайта → получаешь его ключевые слова + подсказки поисковиков.

## 👤 СЕГМЕНТЫ И РАБОТЫ (JTBD)

### Сегмент 1: Владелец малого бизнеса (PRIMARY)

**Пример персоны:** Даниар, 35 лет, директор типографии Winch.uz

**Работа (Job Story):**
```
КОГДА я запускаю новый сайт или хочу улучшить позиции существующего
  → у меня нет SEO-специалиста в штате
  → я не знаю какие запросы используют мои клиенты
  → я вижу что конкуренты выше меня в поиске

ХОЧУ понять какие ключевые слова использовать на сайте
  → без изучения сложных инструментов
  → быстро, за 10-15 минут
  → с конкретным списком слов для копирайтера

ЧТОБЫ получить органический трафик из Яндекса/Google
  → и не платить за рекламу
  → и обогнать конкурентов
```

**Триггеры (когда возникает работа):**
- Запустил новый сайт
- Конкурент обогнал в поиске
- Упал трафик
- Хочу добавить новую услугу на сайт

**Текущие решения (Consideration Set):**
- Ничего не делать (большинство)
- Спросить у знакомого маркетолога
- Посмотреть сайты конкурентов вручную
- Нанять SEO-агентство ($500+/мес)

**Готовность платить:** $10-30/мес

### Сегмент 2: Маркетолог-фрилансер

**Пример персоны:** Азиза, 28 лет, ведёт 5-7 клиентов на SMM + SEO

**Работа (Job Story):**

КОГДА ко мне приходит новый клиент на SEO-продвижение
  → мне нужно быстро показать экспертизу
  → мне нужно собрать семантику для контент-плана
  → у меня нет бюджета на Ahrefs ($99/мес)

ХОЧУ за 30 минут собрать полное семантическое ядро
  → с группировкой по темам
  → с анализом конкурентов клиента
  → в формате для клиента (Excel/CSV)

ЧТОБЫ быстрее закрывать проекты
  → брать больше клиентов
  → выглядеть профессионально

**Триггеры:**
- Новый клиент
- Нужен контент-план на месяц

**Текущие решения:**
- Бесплатный Wordstat (ручная работа)
- Пиратский Ahrefs (риски)
- Keys.so / Serpstat (дорого для фрилансера)

**Готовность платить:** $20-50/мес

## 🔑 КЛЮЧЕВЫЕ РАБОТЫ ПРОДУКТА

### Работа 1: Узнать ключи любого сайта
```
Вход: URL сайта (любого, не только из списка)
Выход: Список страниц + ключевые слова из meta + H1 + title
```

### Работа 2: Собрать все варианты запросов по теме
```
Вход: Базовый запрос ("типография Ташкент")
Выход: 50-200 вариантов из подсказок Яндекс/Google
```

### Работа 3: Понять кто в топе и почему
```
Вход: Ключевой запрос
Выход: Топ-10 сайтов + их title/description + анализ
```

### Работа 4: Экспортировать для работы
```
Вход: Собранные данные
Выход: CSV/Excel для копирайтера или клиента
```

## 🏗 АРХИТЕКТУРА ЧЕРЕЗ РАБОТЫ

### Принцип: Один URL → Все данные

**НЕ ТАК (ограниченно):**
```
Заранее заданные конкуренты: micros.uz, print.uz
↓
Парсим только их
```

**А ТАК (гибко):**
```
Пользователь вводит ЛЮБОЙ URL
↓
Система парсит этот сайт
↓
Извлекает все ключевые слова
↓
Показывает результат
```

### Сущности системы

```
User (пользователь)
└── Projects (проекты — опционально, v2)
    └── ParsedSites (любые сайты которые парсил)
        ├── url, domain
        ├── pages[] — все страницы сайта
        │   ├── url, title, h1, meta_description
        │   └── extracted_keywords[]
        └── parsed_at
    └── Keywords (собранные ключевые слова)
        ├── keyword, source
        └── search_volume (если есть)
```

5. Может отфильтровать/сгруппировать

## 💡 ПРИНЦИПЫ РАЗРАБОТКИ

### 1. Работа первична, фичи вторичны
```
Не "добавить кнопку парсинга"
А "выполнить работу: узнать ключи конкурента"
```

### 2. Любой URL, не список
```
Не "выбери из списка: micros.uz, print.uz"
А "введи любой URL который хочешь проанализировать"
```

### 3. Результат важнее процесса
```
Пользователю не важно КАК мы парсим
Важно ЧТО он получает: список ключевых слов
```

### 4. Простота > Функциональность
```
Лучше 3 работающие функции чем 10 недоделанных
```

## 🔄 КРИТИЧЕСКОЕ ОБНОВЛЕНИЕ: Фокус на Google

### Почему
- 90% поискового трафика в Узбекистане — Google
- Yandex Suggest даёт нерелевантные данные
- Конкуренты ранжируются в Google, не в Yandex

### Изменение приоритетов

| Было | Стало |
|------|-------|
| Yandex Suggest (основной) | Google Suggest (основной) |
| Yandex оставить как опцию | Yandex — опция для РФ клиентов |

### Новая работа: SERP анализ Google

**Job Story:**
```
КОГДА я хочу понять кто мои конкуренты по запросу
  → ввожу "типография Ташкент"

ХОЧУ увидеть топ-10 сайтов из Google
  → с их title и description
  → понять какие страницы ранжируются

ЧТОБЫ:
  → знать с кем конкурирую
  → понять какой контент нужен для попадания в топ
  → спарсить их ключевые слова
```

### Полный flow сбора семантики (обновлённый)

```
1. Ввожу базовый запрос ("упаковка Ташкент")
        ↓
2. Google Suggest → 50-100 вариантов запросов
        ↓
3. Выбираю запрос → SERP топ-10 Google
        ↓
4. Вижу конкурентов → парсю их сайты
        ↓
5. Результат: запросы + кто по ним в топе + их ключи
```

### Ограничения (честно)

**Можем бесплатно:**
- ✅ Google Suggest — популярные запросы
- ✅ SERP топ-10 — кто ранжируется
- ✅ Парсинг мета-тегов конкурентов

**НЕ можем без Ahrefs/SEMrush ($99/мес):**
- ❌ Все запросы по которым ранжируется сайт
- ❌ Точный трафик конкурента
- ❌ История позиций
